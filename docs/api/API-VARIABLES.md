# API Variables

## X-Request-ID

- Type: UUID v4 string
- Required: No
- Generated when omitted: Yes
- Returned on success/error: Yes
- Secret: No

## Content-Type

- Type: media type
- Required: No
- Allowed value: application/json
- Parameters such as charset are accepted.

## Query/path/body

No path, query, or body variables are supported.
