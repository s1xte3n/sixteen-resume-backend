# ADR-004 — Frontend HTTPS Edge

## Decision
Use Azure Front Door Standard/Premium in front of the Azure Storage static website and map `sixteen-resume.mooo.com` to the Front Door endpoint.

## Rationale
Azure Storage static websites do not provide HTTPS for custom domains by themselves. The current public hostname times out, so the edge/DNS path is not operationally verified.

## Consequences
- DNS must route the hostname to Front Door.
- Domain ownership validation is required.
- Use a Microsoft-managed TLS certificate.
- Frontend deployment must purge Front Door cache after updates.
- Production verification must test the custom hostname.
