# ADR-006 — HTTPS/CDN Delivery Feasibility

## Status

**BLOCKED — architecture constraint conflict identified**

## Decision

Retain the approved capability requirement for an HTTPS/CDN delivery layer, but **do not approve Azure Front Door Standard as the production implementation** under the current project constraints.

The Front Door profile created during troubleshooting is a temporary diagnostic resource, not an approved production architecture.

## Blocking Finding

Azure Storage requires Azure CDN or Azure Front Door for HTTPS on a custom domain. Azure CDN Standard from Microsoft (classic) is retired for new instances, while Azure Front Door Standard is the current supported Azure-managed edge option. Current Microsoft pricing lists Azure Front Door Standard with a fixed base fee of about USD 35/month before traffic/request charges. That conflicts with the project's hard R100/month recurring Azure/cloud ceiling.

The architecture therefore has a feasibility conflict between:

1. Azure Storage static website hosting.
2. HTTPS on the approved public hostname.
3. Azure-managed CDN/edge delivery.
4. Total recurring Azure/cloud cost <= R100/month.

No production edge service may be selected until this conflict is explicitly resolved.

## Consequences

- Do not complete the temporary Front Door origin group, route, or custom-domain configuration merely to make the smoke test pass.
- Do not classify the Front Door profile as production infrastructure.
- Delete the temporary Front Door profile if the project owner does not explicitly approve the cost exception.
- Reopen the Phase 3 architecture gate for this decision.
- No frontend API, browser/Cosmos boundary, Function architecture, or persistence design changes.

## Resolution Options

One option must be explicitly approved:

1. Relax the R100/month recurring Azure/cloud ceiling and accept Azure Front Door Standard.
2. Approve a documented challenge deviation allowing a non-Azure-managed HTTPS/CDN service that fits the budget.
3. Change the hosting requirement away from Azure Storage static website to a service with included custom-domain HTTPS, with the Cloud Resume Challenge deviation explicitly recorded.

No option may be selected silently.
