# ADR-005 — CI Deployment RBAC

## Decision
The backend GitHub Actions workload identity receives User Access Administrator or Role Based Access Control Administrator at the production resource-group scope because the ARM template creates role assignments for the Function managed identity.

## Rationale
Contributor does not permit `Microsoft.Authorization/roleAssignments/write`. ARM validation/deployment therefore fails unless the deployment principal has authorization-management permission.

## Security constraint
The elevated role is limited to `rg-sixteen-resume-prod`. The Function managed identity does not receive this administrative role.

## Status
The replacement backend service principal has been prepared. GitHub must be updated to use its new application/client ID.
