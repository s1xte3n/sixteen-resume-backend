# ADR-007 — Cosmos Table RBAC ARM API Version

## Status

**Accepted — Phase 3 blocker correction**

## Decision

Use `2026-03-15` for the ARM resource type `Microsoft.DocumentDB/databaseAccounts/tableRoleAssignments` and for CI verification calls.

## Context

The previous template used `2024-08-15-preview`. Azure deployment validation accepted the template syntax, but the production deployment failed because the Cosmos DB resource provider did not have that API version registered for `eastus`.

The current supported Table RBAC management API is `2026-03-15`.

## Consequences

- ARM deployment can create the Function App's Cosmos Table data-plane role assignment using a provider-supported API contract.
- CI verification uses the same API version as infrastructure.
- No application authentication or data-access model changes.
- The Function App continues to use its system-assigned managed identity and Cosmos Table data-plane RBAC.

## Verification

Phase 3 is not closed by template validation alone. A production deployment must succeed, the role assignment must bind to the current Function App principal, and the `/api/visitors` endpoint must return a successful response.
